FolderDrive는 사용자가 지정한 Android 로컬 폴더와 Google Drive 폴더를 동기화하는 앱입니다. 운영자 및 문의 담당자는 pjm9824이며, 연락처는 pjm9824@gmail.com입니다.

1. 접근하는 정보와 사용 목적

  • Google 계정 정보: 연결한 계정의 이메일 주소, 표시 이름과 Drive 저장 공간 정보를 사용하여 계정을 구분하고 계정 상태를 표시합니다.
  • 파일과 폴더 정보: 선택한 폴더를 동기화하기 위해 파일명, 경로, Drive 파일 ID, 크기, 수정 시간, 변경 버전과 내용 해시를 읽습니다. 사용자가 선택한 방식에 따라 파일 내용을 업로드하거나 다운로드합니다.
  • 인증 정보: Google이 제공하는 인증 기능과 접근 토큰을 사용하여 승인된 Drive 요청을 수행합니다. 앱은 Google 계정 비밀번호를 수집하지 않습니다.
  • 앱 설정과 기록: 연결 계정, 폴더 연결, 동기화 설정, 파일별 결과, 재개 및 변경 판별 정보를 기기에 저장합니다. 기록에는 파일 경로와 크기, 처리 사유가 포함될 수 있습니다.

2. 기기 권한

  • 저장소: 사용자가 허용한 폴더 또는 모든 파일 접근 권한으로 로컬 파일을 읽고 씁니다. Android가 보호하는 영역의 접근 제한은 유지됩니다.
  • 알림과 백그라운드 실행: 동기화 진행·오류·결과를 알리고 백그라운드 작업을 수행합니다.
  • 네트워크와 Wi-Fi: 연결 상태, 과금 여부와 사용자가 정한 네트워크 조건을 확인합니다. Wi-Fi 이름에 따른 허용·차단 기능에는 Android가 요구하는 위치 권한을 사용할 수 있습니다. 앱은 GPS 위치를 요청하거나 위치 이동 이력을 수집하지 않습니다.
  • 생체 인식: Android의 생체 인증 결과로 앱 잠금을 해제합니다. 앱은 지문이나 얼굴의 생체 원본 정보를 수집하거나 저장하지 않습니다.

3. 전송과 제3자 제공

파일은 사용자의 기기와 Google Drive 사이에서 전송됩니다. FolderDrive 운영자는 별도 파일 저장 서버를 운영하지 않으며, 앱에서 접근한 Google 계정 정보나 파일을 운영자에게 자동 전송하지 않습니다. Google API 통신에는 HTTPS를 사용합니다.

앱 자체에 광고·분석 SDK는 포함하지 않습니다. Google 로그인·권한 승인·Drive 저장은 Google 서비스를 사용하며, 해당 서비스가 처리하는 정보에는 Google 개인정보처리방침이 적용됩니다.

FolderDrive의 Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy의 Limited Use 요구사항을 따릅니다. Google 사용자 데이터를 광고, 판매, 범용 AI 모델 학습에 사용하지 않습니다.

4. 보관과 삭제

설정, 동기화 기록과 변경 판별·재개 정보는 기기에 보관합니다. 기록은 기본적으로 30일·20 MB 기준으로 정리하며 사용자가 보관 기간과 용량을 변경하거나 삭제할 수 있습니다. 앱 잠금은 기기에 비밀번호 검증값과 복구 코드 검증값을 저장합니다.

앱에서 계정 연결을 해제하면 해당 계정의 폴더 연결을 비활성화합니다. Google 계정의 타사 앱 연결 관리에서 Drive 접근 승인을 철회할 수 있습니다. 기기의 앱 데이터 삭제 또는 앱 제거로 앱 내부 설정과 기록을 지울 수 있습니다.

앱 제거는 공유 저장소와 Google Drive의 동기화 파일·복구 사본을 삭제하지 않습니다. 직접 내보낸 기록과 설정 백업도 남을 수 있으므로 사용자가 해당 위치에서 삭제해야 합니다. Google Drive 파일을 삭제하려면 Drive에서 해당 파일과 필요에 따라 휴지통을 관리하세요.
